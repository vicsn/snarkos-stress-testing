# Malicious Flood Attack

This test suite lets a set of malicious validators fill their BatchProposals with large pregenerated deployment transactions.

Currently they are pregenerated for 5 and 25 validators on snarkOS commit `e9533b6` in the `pregenerated_txs` folder. If you need more, for a different number of validators or snarkOS commit, you can pregenerate by following instructions in the `../tx_generator` test suite.
